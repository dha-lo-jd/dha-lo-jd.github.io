Car AI DJ

A personal, non-commercial Android app by an individual developer. 日本語はこちら

What it is

Car AI DJ runs on my own phone while I drive. It chooses the next tracks to play in YouTube Music, based on my own listening history and on plain-language preferences I enter (for example, a mood or a type of music). The app is for my own use only: it is not published or distributed, it has no other users, it does not show ads, and it does not make money.

How it uses the YouTube Data API

The app uses the YouTube Data API v3 only to look up public information, with an API key. It does not access any user account data.

  • search.list: find an artist's official channel, or a specific song when the channel does not list it.
  • playlistItems.list: read the public uploads of an artist's official channel to find songs that are new to me.
  • videos.list: check duration, playability and title of candidate videos before adding them to my queue.

Playback is done by the official YouTube Music app. The app does not download, re-host or re-stream any video or audio.

Car AI DJ（個人プロジェクト）

個人が開発している、非営利の Android アプリです。

概要

運転中に、自分のスマートフォンで使う「AI DJ」です。自分の再生履歴と、自分で入力した言葉の好み（雰囲気や音楽の種類など）をもとに、YouTube Music で次に流す曲を選びます。自分だけが使うアプリで、公開も配布もしておらず、他の利用者はいません。広告の表示も、収益化もありません。

YouTube Data API の使い方

YouTube Data API v3 を、API キーで、公開情報の検索にだけ使います。ユーザーアカウントのデータには、アクセスしません。

  • search.list: アーティストの公式チャンネル、またはチャンネルの一覧にない曲を探します。
  • playlistItems.list: アーティストの公式チャンネルの公開アップロードを読み、自分にとって新しい曲を探します。
  • videos.list: 候補の動画の長さ・再生可否・題名を、キューに加える前に確認します。

再生は、公式の YouTube Music アプリが行います。このアプリは、動画や音声のダウンロード、再配信、再ホストをしません。
