Privacy Policy — Car AI DJ

Last updated: 2026-11-22

Car AI DJ is a personal, non-commercial Android app developed by an individual developer. It is used only by the developer, on the developer's own device. It is not published or distributed.

YouTube API Services

This app uses YouTube API Services. By using this app, you agree to be bound by the YouTube Terms of Service.

Google's Privacy Policy: http://www.google.com/policies/privacy

What data the app accesses

The app accesses only public YouTube data (video titles, channel names, video durations, publication years, view counts and public channel uploads) through the YouTube Data API, using an API key. It does not use OAuth, does not access any YouTube or Google account, and does not collect personal information about any person.

What data is stored, and for how long

The data obtained through the YouTube API (video IDs, titles, channel names and IDs, durations, publication years, view counts, and lists of channel uploads) is stored only in a local database on the developer's own device. It is not stored on any server of the developer.

Stored YouTube API data is refreshed or deleted within 30 days of being obtained:

  • Video and channel records are checked against the YouTube API at least every 25 days. Records that are no longer available are deleted.
  • Cached titles, view counts, channel upload lists and similar cached data that are not re-checked are deleted after 28 days.
  • If the app has no API key, such records are deleted without being refreshed.

Data sent to other services

To choose music, the app sends song titles and artist names (some of which were obtained through the YouTube API) to the AI service configured by the developer (Anthropic Claude or Google Gemini), and artist names to Last.fm. No account data or personal information is included. The app also stores the developer's own listening history on the device.

Deleting data

All data stays on the device. You can delete all of it at any time by clearing the app's storage in Android settings, or by uninstalling the app. Because the app does not use Google account authorization, there is no access to revoke in the Google security settings.

プライバシーポリシー — Car AI DJ

最終更新: 2026-11-22

Car AI DJ は、個人が開発している非営利の Android アプリです。開発者本人だけが、自分の端末で使います。公開も配布もしていません。

YouTube API サービス

このアプリは YouTube API サービスを使用しています。このアプリを使用することで、YouTube 利用規約に拘束されることに同意したものとみなされます。

Google プライバシー ポリシー: http://www.google.com/policies/privacy

アクセスするデータ

アプリは、YouTube Data API を API キーで使い、公開されている YouTube のデータ（動画の題名、チャンネル名、動画の長さ、公開年、再生回数、チャンネルの公開アップロード）だけを取得します。OAuth は使わず、YouTube や Google のアカウントにはアクセスせず、個人に関する情報も収集しません。

保存するデータと保存期間

YouTube API で取得したデータ（動画 ID、題名、チャンネル名と ID、長さ、公開年、再生回数、チャンネルのアップロード一覧）は、開発者本人の端末内のデータベースにだけ保存します。開発者のサーバには保存しません。

保存した YouTube API のデータは、取得から30日以内に更新または削除します。

  • 動画とチャンネルの記録は、遅くとも25日ごとに YouTube API で確認し直します。利用できなくなったものは削除します。
  • 取り直さない控え（題名、再生回数、チャンネルのアップロード一覧など）は、28日で削除します。
  • API キーが無い場合は、更新せずに、期限を過ぎた記録を削除します。

他のサービスへ送るデータ

選曲のために、曲名とアーティスト名（一部は YouTube API で取得したもの）を、開発者が設定した AI サービス（Anthropic Claude または Google Gemini）へ、アーティスト名を Last.fm へ送ります。アカウント情報や個人情報は含みません。また、開発者自身の再生履歴を、端末に保存します。

データの削除

データはすべて端末内にあります。Android の設定でアプリのストレージを消去するか、アプリをアンインストールすれば、いつでも全て削除できます。Google アカウントの認可を使わないので、Google のセキュリティ設定で取り消すアクセス権はありません。
